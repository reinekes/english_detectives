# The Last Letter — The Ashford Affair

> **Спойлеры:** документ раскрывает убийцу и полную логику дела.

Оригинальное вымышленное викторианское дело для учебного прототипа английского уровня B1. Герои, события и цитаты созданы для этой игры. Историческое медицинское заключение не моделируется: вывод Ватсона о временном промежутке является установленным фактом внутри вымышленного дела. Конкретное вещество и способы его получения не называются.

## Завязка

14 ноября 1891 года сэр Эдмунд Эшфорд найден мёртвым в своём кабинете. Рядом стоят чашка чая и незаконченное письмо о пропавших благотворительных деньгах. Холмс с помощью игрока проверяет четверых подозреваемых. Для завершения нужны чашка, бухгалтерская книга, расписка за телеграмму и три правильных вывода. Для вывода о мотиве дополнительно читается письмо.

**Виновен Артур Рид**, секретарь. Он присвоил 200 фунтов благотворительного фонда, чтобы погасить личный долг. Эшфорд обнаружил пропажу и собирался в девять часов обратиться в полицию. Рид отравил его личную чашку во время визита в кабинет, а затем пытался создать алиби отправкой телеграммы со станции.

## Шесть улик

| ID | Улика | Место | Что доказывает | Чего не доказывает |
|---|---|---|---|---|
| `letter` | Незаконченное письмо | Кабинет | План обращения в полицию, сумму и срок | Личность адресата: верх листа оторван |
| `cup` | Фарфоровая чашка и заключение | Кабинет | Яд только в личной чашке; критический промежуток; один посетитель | Личность посетителя без расписки |
| `watch` | Разбитые карманные часы | Холл | Время обнаружения тела | Точное время добавления яда |
| `ledger` | Бухгалтерская книга с банковской квитанцией | Кабинет полицейского участка | Присвоение Ридом 200 фунтов; мотив | Само действие отравления |
| `telegram` | Расписка за доставку телеграммы | Кабинет полицейского участка | Рид у стола Эшфорда в 8:10; ложность алиби | Мотив без книги |
| `thread` | Чёрная нить | Холл | Нить принадлежит шторе | Причастность Элеоноры; одинаковый цвет недостаточен |

Участок хранит изъятые Лестрейдом документы; станция упоминается только как место заявленного алиби Рида и отправки его собственной телеграммы. Это два разных места. Если интерфейс использует внутренний ID `station` для полицейского участка, видимая подпись должна уточнять `Police station`.

## Три вывода

| ID | Необходимые улики | Верный ответ | Логика |
|---|---|---|---|
| `poisoned-cup` | `cup` | `cup` | Общий чай и сахар чисты; яд только в чашке |
| `false-alibi` | `telegram` | `reed-study` | Посыльный, подпись и Джеймс помещают Рида в кабинет в 8:10 |
| `missing-money` | `letter`, `ledger` | `reed-theft` | Книга называет получателя денег; письмо объясняет срочную угрозу разоблачения |

Решение уникально в пределах установленных фактов дела: из четырёх подозреваемых только Рид присутствовал в кабинете в установленный промежуток. Три другие версии исключены внешними свидетелями. Книга объясняет конкретный мотив, а ложное алиби подтверждено документом и двумя свидетелями. Разбитые часы не используются как точное время убийства, одинаковый цвет нити не выдаётся за совпадение материала.

## Контракт данных

`baker-street/dist/case-data.js` экспортирует `CASE`, `PEOPLE`, `CLUES`, `WORDS`, `DEDUCTIONS`.

- `PEOPLE`: четыре объекта, по три вопроса. Ответы и описания имеют русский перевод. `unlocks` содержит ID дополнительных доступных улик, без обязательной последовательности допроса.
- `CLUES`: ровно шесть объектов; `location` — видимая подпись места. Каждая улика имеет краткое и полное описание с переводом, а также `wordIds`.
- `DEDUCTIONS`: три задачи с тремя вариантами; `requires` задаёт улики, которые надо собрать перед ответом.
- `WORDS`: 16 слов с IPA, русским переводом, простым английским определением и примером.
- `CASE.initialClues` пуст: улики приобретаются осмотром или вопросами.
- `CASE.requiredClues`: `cup`, `telegram`, `ledger`. `CASE.requiredDeductions` перечисляет все три вывода. Требование письма обеспечивается зависимостью третьего вывода.

Все шесть улик доступны через три места. Допрос Рида также открывает расписку, Элеоноры — книгу, Мерсера — чашку. Эти открытия помогают игроку, но не создают блокирующего порядка действий.
